ZEROHOUR

Inteligencia de vulnerabilidades · por Adrián López Olaria

Un briefing de vulnerabilidades que se compila solo cada mañana: NVD, CISA KEV y SSVC, FIRST EPSS, exploits de Metasploit, Exploit-DB y Nuclei, PoC públicas, GitHub Advisories, avisos de INCIBE-CERT y CERT-EU y prensa especializada. Web estática; los datos son JSON que regenera un job programado.

Diseño y desarrollo: Adrián López Olaria · Castellón

Cómo se puntúa

score = 3 · CVSS
      + 20 · EPSS (percentil)
      + 25 · explotada (KEV; SSVC activa: 20)
      + 5 · ransomware
      + 15 · exploit verificado (PoC: 6)
      + 5 · stack

Una CVE explotada nunca baja de 70, ni de 85 si además afecta al stack, se usa en ransomware o tiene exploit verificado.

Una CVE sin puntuar aún no suma 0 por CVSS: se le asigna un valor neutro del 40 % y su score es provisional (marcado con «prov.») hasta que se analice.
